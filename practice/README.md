# BullCamp 离线实操包

本包是课程原创代码，使用 Python 3 标准库。没有网络请求、第三方依赖、API 密钥或证券交易。`prices.csv` 全部为虚构价格，不能用于判断现实策略有效性。

## 从网页下载后开始

下载 `bullcamp-practice.zip` 并解压，得到 `practice/` 文件夹。在它的上级目录打开终端，执行下面的命令。项目目录版已经包含这些文件，不需要重复下载。

## 实验一：读账本，再改参数

```bash
python3 practice/lab.py --config practice/config.json --output experiment.json
python3 -m unittest discover -s practice -p 'test_lab.py'
```

1. 先预测提高 `fee_rate` 会怎样影响现金和费用。复制配置，只改费用，再输出另一份文件。
2. 找出每期 `cash + shares * price = equity`；买卖费用均扣现金。
3. 对比同成本持有基准和零费用规则，解释二者回答的问题不同。
4. 固定窗口和仓位，保留输入、数据哈希、输出和限制。不要只保存好看的结果。

每个段从 10,000 现金独立开始，信号只使用之前价格，当前给定价格成交，允许碎股。无分红、税、滑点、冲击和借款，现金收益为零。策略按每期目标权重再平衡，不是“买入后永不调整”。净收益是给定段的简单资产收益，不年化。

文件用 train / validation / test 展示实验分工，但数据非常小且可直接阅读，也会一次输出所有结果。它不是保密测试平台。看过测试结果后再调参，必须记录“测试数据已参与选择”，不能宣称新的独立样本外证明。网页第八章另有先锁定再揭示的教学实验。

## 实验二：修复费用函数

```bash
python3 practice/test_exercise.py
```

初次运行预期有两个失败，这是有意保留的学习任务。修改 `exercise.py` 的两个 return，使买卖都扣成交额乘费率，再运行。零成交、零费用、买卖方向都要通过。参考实现放在 `lab.py`，建议先自己修。

给 Codex 的任务可以写成：

> 检查 exercise.py 的买卖现金函数。先说明当前行为和应有行为，再修改费用逻辑；保留函数接口，用 test_exercise.py 验证。解释这几个测试不能覆盖什么。不要联网或连接账户。

这段代码只计算**已给定成交数量**后的余额；不会自己保证订单可负担。`lab.py` 的执行层在买入前另外限制数量。这是读开源项目时要区分的职责。

## 进入真实项目

按网页“补充实践”中的固定 commit 阅读 README、环境和配置，或参阅 `docs/课程来源与实操审校.md`。课程的 JSON 和函数不是上游接口。不要将离线实验通过写成第三方 Agent 已运行。

真实执行后填写 `run-record.md`。输入与来源要留档，密钥不进入报告、git 或网页存档。额度、供应商和数据权限由使用者自行设置；轮数限制不等于硬性费用上限。
