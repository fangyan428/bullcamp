# 课程来源与实操审校

核查日期：2026-09-23。适用范围：6 个基础任务与 10 章、每章 4 个主线任务，共 46 个核心任务。本文只核对来源、课程边界及补充实践；未安装或执行第三方项目，未调用模型或金融数据服务。

## 发布口径

46 个任务全部应能使用内置资料、确定计算和明确标记的 Agent 教学样本完成。基础知识、投资操作与 Agent 审核在同一任务中练习。真实项目安装、模型 key、数据权限和付费服务只属于补充实践，不能作为解锁、评分或毕业条件。下述公开来源是延伸阅读和审校依据，外链暂时不可用也不能阻塞核心学习。

网页应区分三类结果：**内置计算结果**、**Agent 教学样本**、**真实项目运行记录**。修改教学配置后产生的规则反馈可以称“根据配置生成的教学反馈”，不可称为已调用 LLM。纯教学生成的公司、财报和行情也需标为虚构；真实来源用于解释原则，不给虚构数字背书。

## 6 个基础与 10 个主线主题的内容审校

以下“验收”是本项目的教学设计建议；引用支持相关知识，未声称官方机构认可该游戏。

| 主题 | 容易误教的点与应采用的口径 | 核心任务可用的无需 API 验收 |
|---|---|---|
| F01 账户为何增加 | 存入不是投资收益。对定义好的账户，区间投资损益 = 期末权益 − 期初权益 − 存入 + 取出；含多次现金流时，不把它随意除以累计本金称为精确收益率。计算器利率是情境输入，不是收益预测。S01、S02 | 从账本拆出外部资金与损益；核对两期复利 |
| F02 风险是什么 | 风险包括不确定性、永久损失和流动性，不只等于价格波动；较高风险不保证较高实际回报。互斥结果的概率平均与连续两期复利是不同计算。S03、S13 | 比较给定分布，说明资金期限与损失承受能力 |
| F03 企业赚钱与股东所得 | 收入、利润、经营现金流不相等。以三张报表入门是简化；完整披露还包括权益变动、附注等。不要把企业总利润直接当每股所得。S09、S10 | 把赊销、借款、购设备分别放入简表并解释 |
| F04 价格与未来 | 估值依赖现金、增长、风险和时间的假设；高增长也需要投入。改变折现率或增长时，要写明其他假设保持不变。S13 | 对给定现金流调一个参数，先预测方向再计算 |
| F05 公平比较 | 同一目标、资金到达时间、期间、基准和成本口径再比较。两只相似持仓的 ETF 不自动形成分散。S02、S04、S06、S07 | 找出提前使用未来工资或忽略现金余额的对照 |
| F06 结论的证据 | 分清事实、推断与假设；有引用不代表数字、期间和单位已正确；多 Agent 共识不等于独立证据。S10–S13、S16、S18 | 从固定材料核对一个数字、一项推断和可得日期 |
| C01 指数与投入计划 | 指数不是可直接买入的基金；基金可能有费用和跟踪偏差。定投是投入节奏，不替代资产选择。已有整笔钱分批投入与工资到账即投不是同一资金约束；不保证盈利或必胜一次投入。S04–S07 | 在多条虚构路径上比较份额、总投入、现金和结果 |
| C02 可管理的账户 | 再平衡主要恢复风险配置；不是保证增加收益。买卖改变现金与持仓，但不把两者重复算入净值；费用计入一次。S02、S04、S07、S08 | 用新资金或交易两种方式恢复目标并核对账本 |
| C03 公司研究 | 10-K 是公司编制的披露，不是 SEC 对准确性的背书。读业务、风险、附注和口径，不能只抓一项比率。S09–S12 | 用有日期和单位的虚构披露完成来源摘录与异常表 |
| C04 估值与预期 | 相对倍数是比较工具；盈利、风险和增长口径不同会影响比较。简化永续模型须标明适用假设；若使用 `CF1/(r−g)`，要求 `r>g`，并禁止不适用情境计算。S13 | 三情境敏感性表与价格隐含预期；不设“唯一真实价值” |
| C05 价值与成长 | 低 P/E 不自动便宜，增长快也不自动值得买；风格化名人提示词不是本人意见。比较证据、假设和失效条件，不能靠角色投票。S09、S10、S13、S16 | 同一资料用两种解释，列出各自最强反证 |
| C06 消息与更新 | 区分事件发生、公开发布、申报、数据取得、分析及成交时间。会计期间结束不等于数据已公布；最新重述数字不能冒充历史时点已知数字。S11、S12；预期与市场反应见 S13 | 对时间线排序，剔除决策时尚不可得的材料 |
| C07 规则与执行 | 技术信号只是可检验规则，不是买卖保证。市价单不保证指定价格；限价单不保证成交；止损触发后仍有价格风险。信号用当日收盘数据时，不能无条件假定此前已按该价成交。S08、S13、S20 | 对同一信号切换成交/仓位假设，预测并检查订单 |
| C08 策略检验 | 基准、成本、数据时点、样本和测试段必须固定。测试集一旦反复用于挑参数，就失去独立检验作用；少量样本或漂亮曲线不能证明稳定能力。S02、S12、S13、S18、S20 | 内置训练/验证/未见样本，记录一次受控修改与失败 |
| C09 价差与资金压力 | 同步可复制现金流的纯套利与并购/配对等风险交易分开。对冲不等于没有路径风险；价差先扩大可能带来资金压力。保证金要求可改变，券商可能无需预先通知即平仓。S13–S15 | 用情境保证金参数计算权益和缺口，经历成交失败、借券限制或并购失败 |
| C10 独立研究 | 评价目标、证据、操作与修正，不按模拟盈利排名；任何外部项目的实际运行都不是核心毕业要求。S03、S04、S13；工具边界 S16–S20 | 新角色与新材料：独立选工具、纠错、改教学规则、导出完整复盘 |

额外实现提醒：模拟保证金参数必须写“本情境假设”，不要把某个固定比例或旧版日内交易门槛讲成通用现行规则。S14 已出现更新后的日内保证金说明。SEC 的 XBRL frames 提取最近申报且贴近给定期间的数字，不能直接当历史时点快照；此外不同公司财务日历并不完全相同。上述数据时点检查是根据 S12 的数据结构所做的课程应用推论。
