- 6 个基础任务、10 章各 4 个任务，共 46 个；184 项结构化检查、92 项新情境题。
- 每关包含原创情境、两段短讲解、例题、资料、实操、明确标注的 Agent 教学样本、迁移检查和自评复盘。

- 主线不使用 API。资料与参数、首次作答、订正、任务草稿和复盘保存在独立版本化存档。
- 真实开源项目仅提供已核查版本的阅读与实践指引；上游未实跑。

## 验证中修复的问题

1. 通用计算器默认值与个别情境账本不一致：逐关指定初始参数，并增加一致性检查。
2. 折现率输入的 `min` 与 `step` 组合导致浏览器拒绝默认值：修正步长，加入默认值满足浏览器步长的验证。
3. 手机导航和实验中的长 JSON 横向溢出：调整小屏导航与内容最小宽度、换行规则。
4. 内置浏览器的 Blob 下载事件与系统确认框不稳定：改为生成可见导出预览和明确保存链接，提供文本迁移；导入/重置采用页面内确认。

## 边界与未执行项

- 自动化浏览器测试中的自评文本是标明用途的验收占位，不是学习效果测量。通关检查不能替代真实新手的教学体验评估。
- 单文件通过 HTTP 入口验证了内联运行，并静态检查无外部脚本/样式依赖；未逐一测试各操作系统双击 `file://` 的存储策略。浏览器禁止存档时仍可生成导出文本。
- 内置浏览器下载事件未可靠返回；已验证导出内容、存档恢复与实际 ZIP 文件。保存链接使用标准浏览器下载机制，未宣称所有浏览器下载行为均已测试。
- 没有安装或执行 TradingAgents、AI Hedge Fund、Qlib、RD-Agent；没有调用真实数据/模型 API 或进行交易。版本、接口与限制的源码审查不等于实跑。
- 没有托管发布。预览服务器仅绑定本机，单文件与 ZIP 可以脱离服务器使用。

新课程保留原版代码、MIT 许可和 `bullcamp_state` 存档；源码目录入口为 `index.html`，原版入口为 `classic.html`。
