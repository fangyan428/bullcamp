2026-09-23，依据用户最新授权执行。本文件是当前范围；此前确认稿、融合稿为设计背景，不再作为真实 API 必修的依据。

## 交付目标

完成 6 个基础任务、10 章 40 个融合任务。主线全部使用原创材料、可复现模型、教学 Agent 记录和本地操作，不依赖登录、API 或外部数据。真实项目实践附在相应任务中，单独记录，不阻塞课程与毕业。

起点：认识 BullCamp 基本概念，金融分析仍是新手；用户能读写 Python，能借助 Codex 修改代码。课程不要求先读大段教材。每个任务包含简短讲解与例题、实操、Agent 审核、新情境检查和带依据的学习记录。

完整任务清单与逐关操作见 [课程地图](课程地图.md)。

## 核心能力与覆盖

基础：收益与现金流、风险、企业报表、折现直觉、公平比较、事实与推断。

主线：指数与定投、账户与再平衡、财报研究、估值、价值/成长、信息与事件、动量/择时、策略验证、套利实施风险、理念匹配与毕业研究。将《Investment Philosophies》作为内容索引，而非照搬原书文字或要求通读。所有数值情境注明简化与虚构性质。

实操包含：资金计划、订单与费用、账本核对、财报取数、估值参数、策略规则、数据时点、配置阅读与修改、Agent 任务约束、证据核查、反证和复盘。每关至少一个实质动作。

## 实现结构

- 保留原版源文件与 MIT 许可，通过 classic.html 访问原版，保护原存档。
- 新主入口提供学习地图、任务工作台、方法手册、复习与档案；使用独立版本化存档。
- 使用显式任务数据、独立数学模型与分步引擎；资料在整个任务中可回看。
- 教学 Agent 输出明确标识为编写的演示记录。用户可以检查、选择、改写任务和记录判断；不伪装联网生成。
- 真实实践提供上游源码链接、固定提交、配置修改步骤、验收清单，以及离线 Python 练习包。没有真实服务时不标注真实运行完成。
- 支持本地 HTTP 启动与单文件离线分发；按用户 2026-09-23 最新授权部署到 GitHub Pages，线上只包含新版探索营。不接真实证券账户。

## 评分与持续学习

计算和结构化任务确定判分；开放判断采用量规和自查，明确区分自动核验与自评。不按模拟收益排名。提示后可继续学习，独立变体检查后再记掌握。保留每步输入、中途位置、首次作答、错因和可导出的复盘。
