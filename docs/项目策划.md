# 美股新手村 · BullCamp — 项目策划书

> 一个"多邻国式"的美股投教小游戏：每天 5 分钟，把小白从「韭菜幼苗」养成「传奇操盘手」。

- 版本：v1.0（MVP 策划）
- 日期：2026-07-15
- 形态：纯前端 Web 小游戏（手机优先），本地存档，可后续接入 App / 服务端

---

## 1. 项目概述

### 1.1 一句话定位

**把美股基础知识拆成 200 道游戏化小题，用多邻国的「连胜 + 关卡 + 即时反馈」机制，让零基础用户每天主动回来学 5 分钟。**

### 1.2 目标用户

| 画像 | 描述 | 典型痛点 |
|---|---|---|
| 纯小白 | 从没开过户，听说过"美股七姐妹" | 觉得炒股 = 赌博，术语全看不懂 |
| A股移民 | 炒过A股，刚开美股户 | 带着 A 股习惯踩坑：以为红涨绿跌、以为有涨跌停、不知道盘前盘后 |
| 被割过的 | 买过 TQQQ 拿了半年不明白为啥亏 | 不理解杠杆 ETF 磨损、保证金、期权时间价值 |

### 1.3 北极星指标

- **次日留存**（打完第一关后第二天是否回来）
- **7 日连胜达成率**（衡量习惯是否养成）
- 辅助：单关完成率、错题复习率、平均每次使用时长（目标 4-8 分钟，刻意不做长）

### 1.4 为什么是多邻国模式

多邻国把「学外语」这件反人性的事做成了日活过亿的游戏，核心可迁移机制：

| 多邻国机制 | 心理学原理 | 迁移到投教 |
|---|---|---|
| 微课（每关 3 分钟） | 降低启动成本 | 每关 6-8 题，一部电梯的时间 |
| 即时反馈（对错立刻响） | 操作性条件反射 | 答完立刻绿/红 + 一句人话解释 |
| 生命值 ❤️ | 损失厌恶 → 认真答题 | 每关 3 颗心，答错扣心 |
| 连胜 Streak 🔥 | 沉没成本 + 承诺一致性 | 每天学 1 关点亮火焰，断一天清零 |
| XP / 等级 / 徽章 | 可见的成长 | 韭菜幼苗 → 传奇操盘手称号体系 |
| 关卡地图（蜿蜒路径） | 目标梯度效应 | 6 大单元 30 关，Boss 战收尾 |
| 错题重现 + 间隔复习 | 遗忘曲线 | 错题本 + 每日挑战混出旧题 |

投教比语言学习多一个天然优势：**市场每天都在发生新故事**，学到的知识当晚就能在新闻里验证——我们用「当前美股处于盘前/盘中/盘后」的实时状态条把这层连接做进产品。

## 2. 教研设计（课程内核）

### 2.1 教研三原则

1. **场景先于概念**：不先讲定义，先给情景。"凌晨 2 点你想卖掉手里的特斯拉，能成交吗？"——答完再给概念卡。
2. **误区即考点**：小白（尤其 A 股移民）的每个典型误区都是最好的干扰项。红涨绿跌、T+1、涨跌停、100 股一手——全部反着考一遍。
3. **数学必须动手**：杠杆磨损这种反直觉知识，让用户自己算一遍「100 → +10% → -10% = 99」，比十句解释都管用。

### 2.2 知识树（v6 重排 · 10 单元 · 50 关 · 320 题）

> v6 架构重梳理（响应用户反馈：补金融基础知识——估值、融资、股票的本质）。主线逻辑：
> **是什么 → 为什么值钱 → 在哪买 → 怎么买 → 怎么看 → 怎么估 → 高级武器 → 防身术**，之后是两个进阶选修（港股、3倍ETF）。
> 操作知识（2-5）被"本质层"（1-2）和"判断层"（6）夹住：先懂原理再学操作，学完操作立刻学判断。

| # | 单元 | 回答的问题 | 层 |
|---|---|---|---|
| 1 | 🐣 新手村：股票是个啥 | 股票/股东/指数是什么 | 本质 |
| 2 | 💸 公司与钱：金融基础课 | 公司为什么值钱？钱怎么流动？ | 本质 |
| 3 | 🗺️ 市场地图：几点开门 | 去哪买、几点买 | 操作 |
| 4 | 🎯 下单基本功 | 怎么下单不吃亏 | 操作 |
| 5 | 📊 看懂行情 | 屏幕上的数字什么意思 | 操作 |
| 6 | ⚖️ 估值课：给公司称重 | 这价格贵不贵 | 判断 |
| 7 | ⚡ 杠杆特训营 | 高级武器怎么伤人 | 风险 |
| 8 | 🛡️ 韭菜防身术 | 怎么不被割（主线毕业） | 风险 |
| 9 | 🇭🇰 港股入门 | 第二个市场的规则差异 | 进阶 |
| 10 | 🎢 3倍ETF特训 | 最烈的武器的使用执照 | 进阶 |

**单元 1 · 新手村：股票是个啥** 🐣（3 关 + Boss）
- 股票与股东：所有权碎片、分红、代码 ticker、IPO 为什么上市
- 股价为什么涨跌：供需与预期、市值 = 股价 × 股本
- 三大指数认亲：道指 / 标普 500 / 纳指分别代表什么

**单元 2 · 公司与钱：金融基础课** 💸（4 关 + Boss，v6 新增）★ 用户点名需求
- 公司为什么值钱：赚钱机器、利润是价值源头、买股票=买未来赚钱能力
- 融资的一生：自掏腰包→天使→VC→IPO→增发；股权 vs 债权融资；稀释的逻辑
- 一级市场与二级市场：你买腾讯的钱腾讯拿不到；打新
- 分红与回购：回购=变相分红；不分红≠坏公司（亚马逊）

**单元 6 · 估值课：给公司称重** ⚖️（4 关 + Boss，v6 新增）★ 用户点名需求
- 价格与价值：股价 500 的不一定贵；好公司≠好股票
- PE 实战（含"奶茶店估值器"实验）：倍数=市场情绪温度计、15-20 倍历史常温锚
- PB/PS：没利润看 PS、重资产看 PB，不同行业不同尺子
- 估值的锚：跟历史比、跟同行比、跟利率比（盈利收益率 = 1/PE）

**单元 3 · 市场地图：去哪儿、几点开门** 🗺️（4 关 + Boss）★ 用户点名需求
- 纳斯达克 vs 纽交所：1792 梧桐树 vs 1971 全电子化，上市地 ≠ 公司好坏
- 交易时间与时差：美东 9:30-16:00，北京时间夏令/冬令时换算，T+0、无涨跌停
- 盘前盘后：4:00-9:30 / 16:00-20:00 ET；流动性低、点差大、财报都在盘外发
- 熔断与停牌：标普 7%/13%/20% 三档，个股 LULD

**单元 3 · 下单基本功** 🎯（4 关 + Boss）
- 市价单 vs 限价单（打车比喻：马上走 vs 等一口价）
- 买一卖一与点差：隐形成本
- 1 股起买与碎股、手续费
- 止损单止盈单、跳空风险

**单元 4 · 看懂行情** 📊（4 关 + Boss）
- K 线：开高低收；**美股绿涨红跌，和 A 股相反**（高频误区）
- 成交量与量价关系
- 市值 / EPS / PE：估值第一课
- 财报季：beat 了为什么还会跌（预期博弈）、指引

**单元 5 · 杠杆特训营** ⚡（5 关 + Boss）★ 用户点名需求，本产品的教研深水区
- 杠杆是什么：借钱放大收益也放大亏损，2 倍杠杆跌 50% 归零
- 保证金与爆仓：维持保证金、Margin Call、强平、利息
- 杠杆 ETF 是什么：TQQQ/SOXL，「3 倍」指的是**当日**涨跌幅
- 磨损的数学 ★：波动损耗——标的 +10% 再 -10% = -1%，3 倍 ETF +30% 再 -30% = **-9%**；每日再平衡机制；为什么适合短线不适合躺平
- 做空：借股票卖、亏损理论无上限、轧空（GME）

**单元 6 · 韭菜防身术** 🛡️（4 关 + 毕业考）
- 追涨杀跌与 FOMO：情绪周期
- 仓位与分散：不 all in、定投
- 骗局识别：荐股群、"内幕消息"、保本高收益 = 诈骗
- 长期与复利：72 法则、"在市场里的时间" vs "择时"

**单元 7 · 港股入门** 🇭🇰（4 关 + Boss，v5 新增）★ 双市场刚需
- 认识港股：港交所、恒生指数/恒生科技指数、港币与联系汇率
- 交易时间与午休：零时差、早市/午休/午市（含"港股下单时钟"实验）
- 一手制度：按手买卖、一手股数各不同、碎股市场
- 港股规则彩蛋：双向印花税 0.1%、T+0 交易 T+2 交收、VCM 市调机制、港股通与南向资金

**单元 8 · 3倍ETF特训** 🎢（4 关 + Boss，v5 新增）★ 用户点名需求，u5 的实战进阶
- 3倍做多家族图鉴：TQQQ / UPRO / SOXL、单股杠杆 ETF（NVDL）
- 反向 ETF：SQQQ、不融券做空、反向同样磨损
- 使用纪律：短线单边、小仓位、必设止损、0.9% 费率 vs QQQ 0.2%
- 2022 年的教训：纳指 -33% vs TQQQ -79%、回本数学（含"2022熊市回放机"实验，真实历史行情）

### 2.3 题型体系（5 种）

| 题型 | 交互 | 适合考察 | 占比 |
|---|---|---|---|
| 单选 choice | 四选一 | 概念辨析、情景决策 | ~40% |
| 判断 tf | 对 / 错 | 误区粉碎（"美股也有涨跌停"→错） | ~20% |
| 配对 match | 左右连连看 | 术语↔解释、时段↔特点 | ~15% |
| 排序 order | 拖拽排顺序 | 流程、时间轴（盘前→开盘→收盘→盘后） | ~10% |
| 选词填空 blank | 词库填空 | 关键数字、关键词 | ~15% |

### 2.4 教-考闭环铁律（v4 新增 · 最高优先级）

> 用户反馈原话："这些问题小白也没认知呀，如何让他们一上来就答题。"

**铁律：永远不考没教过的东西。** 每道题作答所需的全部信息必须来自：①本关知识卡片（一张卡最多讲 1-2 个新概念）②题面「📖 新知识」微教学（teach 字段，≤70字，显示在题目上方，读两行→立刻用→答对）③之前关卡反复教过的概念 ④生活常识。四者皆无 = 违规题。

配套规则：
- **零门槛起步**：每关第 1 题必须是读完卡片/微教学后闭眼能答对的送分题——首次接触新知识时，成功体验比考倒用户重要一万倍（多邻国新词题就是零失败设计）
- **关内递进**：直接套用 → 变体确认 → 情景应用 → 轻计算/辨析
- **干扰项卫生**：干扰项只准用教过的术语或中国用户熟知的事物（考美股大盘指数，干扰项用"上证指数"而不是"罗素2000"——前者错得有教学意义，后者只是噪音）
- **拐杖分级**：teach 只在学习模式显示；Boss 战、每日挑战、错题复习是回忆模式，不给拐杖
- **实验前置**：有动手实验的关卡，题目可以假设用户已亲手操作过（先做后考）

### 2.5 内容规范（写题 SOP）

- 每关开头 1 张**知识卡片**（≤150 字，必须有一个生活比喻），然后 6 题；Boss 战 8 题无卡片
- 每题 explanation = 一句结论 + 一句原因/比喻，≤60 字，答对答错都展示（对 = 强化，错 = 纠正）
- 干扰项必须是"真实存在的误区"，不出脑筋急转弯
- 语气：朋友聊天，可用梗，不油腻，不说教；情景题用"你"开头
- 事实红线：交易时间、熔断规则、杠杆数学等硬数字必须准确，内容生产后过独立审校

### 2.6 互动实验室（v3 新增 · 任天堂式"做中学"）

答题是「考」，实验是「玩」。参考任天堂关卡设计哲学（机制即教程、失败廉价且好笑、顿悟由玩家自己触发）与卡牌游戏的收集回路，在 6 个关键关卡中嵌入可操作沙盘，流程变为：**知识卡片 → 动手实验 → 答题验证**。

| 实验 | 所在关卡 | 玩法 | 要顿悟的知识 |
|---|---|---|---|
| 磨损制造机 | u5l4 | 按"涨10%/跌10%/震荡4天"按钮，看标的与3倍ETF两条线分叉 | 波动损耗：震荡市里杠杆ETF自己融化 |
| 爆仓模拟器 | u5l2 | 选杠杆倍数逐日过行情，任务是"把自己玩爆仓" | 杠杆放大一切+维持保证金强平线 |
| 下单时钟 | u2l3 | 拨动美东/北京双时钟，在不同时段下单看遭遇 | 盘前盘后流动性差、休市排队跳空 |
| 点差实验室 | u3l2 | 在苹果和冷门小票上分别用市价/限价单买入 | 点差=隐形成本，限价保价不保成交 |
| 捏K线 | u4l1 | 拖4个滑杆捏出指定形态的K线 | 开高低收+绿涨红跌+长上影含义 |
| 复利时光机 | u6l4 | 调年化和年数滑杆，任务"让1万变4万" | 72法则、时间是最大杠杆 |
| 奶茶店估值器 | u10l2 | 拖利润和PE滑杆完成常温/发烧/遇冷三次定价 | 估值=利润×倍数，倍数是情绪温度计 |
| 港股下单时钟 | u7l2 | 拨港股时钟在早市/午休/收市后下单 | 零时差、午休停摆、连续交易差异 |
| 2022熊市回放机 | u8l4 | 按季度回放2022真实行情看两条线 | 纳指-33% vs TQQQ-79%、回本数学 |

设计规范：每个实验有一个**明确任务**（目标梯度）、操作即时反馈（≤100ms）、达成后弹"实验结论"卡（把顿悟固化成语言）、奖励 +15 XP、可跳过不设墙。

### 2.7 知识卡牌图鉴（收集回路）

每关首次通关掉落一张**术语卡牌**（N/R/SR/SSR 四档稀有度，Boss 关和核心概念掉 SSR），卡面=术语+一句人话解释。图鉴在「我的」页展示，未拥有的呈剪影态制造收集欲。卡牌本质是**可收集的知识点摘要**——玩家为了集卡反复回看术语，就是变相的间隔复习。后续可扩展"概念合成"（股价+总股本 → 合成市值卡）。

### 2.8 记忆机制

- **错题本**：答错自动收录，按单元分组，随时可发起 10 题复习局；复习答对即移出
- **每日挑战**：每天 5 题，从已学关卡随机混出（间隔复习的低配实现），完成即保连胜
- **Boss 战**：单元内所有知识点混合考，通关才解锁下一单元

## 3. 产品设计

### 3.1 核心循环（Habit Loop）

```
提示：打开 App 看到 🔥 连胜数 + "当前美股：盘前" 状态条
  ↓
行动：打 1 关新课（4 分钟）或 每日挑战（2 分钟）
  ↓
奖励：XP + 星星 + 连胜 +1 + 可能弹徽章 + 撒花动画
  ↓
投入：连胜越长越不舍得断（沉没成本）→ 明天再来
```

### 3.2 数值系统

- **XP**：首答对 +10，重答对 +5，通关 +20，Boss +40，每日挑战每题 +10
- **星星**：按首答正确率结算，≥90% 三星 / ≥70% 两星 / 通关一星（可重打刷星）
- **生命值**：每关 3 颗（Boss 4 颗），答错 -1，归零关卡失败可重来——制造适度紧张感
- **称号**（按累计 XP）：韭菜幼苗 🌱 → 见习股民 → 图表学徒 → 财报侦探 → 风控骑士 → 华尔街之狼预备役 → 传奇操盘手
- **徽章**：新手上路 / 三日之约 / 七日火焰 / 六大单元通关徽章 / 满分 Boss / 错题清道夫 / 千钻大佬…

### 3.3 功能清单

**MVP（本期）**
- 关卡地图（解锁进度可视化）、5 种题型引擎、即时反馈卡
- 连胜 / XP / 星星 / 称号 / 徽章
- 每日挑战、错题本、个人页（数据 + 连胜日历）
- 实时市场状态条（盘前/盘中/盘后/休市，America/New_York 时区实时计算）
- 本地存档（localStorage），断点续学

**后续路线**
- 服务端账号 + 排行榜 / 好友 PK（多邻国 Leaderboard 联赛制）
- 推送提醒（连胜将断时的"内疚式"文案是多邻国留存王牌）
- 内容扩包：期权入门、财报深读、宏观数据日历
- 与 RockFlow/Bobby 打通：学完「盘前盘后」直接跳转真实盘前行情页；答题送模拟盘体验金
- 题目与实时行情联动（"今天英伟达财报盘后发布，你觉得……"）

### 3.4 关键取舍

- **不做**注册登录、不做长视频课、不做社区——一切为「每天 5 分钟」让路
- **心值不做全局恢复制**（多邻国式 5 心 + 时间恢复需要服务端与商业化配合），MVP 用每关 3 心，失败可立即重试，保留紧张感去掉挫败感
- 关卡**线性解锁**不做自由跳级：小白不知道自己不知道什么，路径感 > 自由度

## 4. UX 设计

### 4.1 视觉语言

- **品牌色**：紫色 #6C4CF1（主）+ 黄色 #FFC83D（点缀）——延续 RockFlow 紫黄基因
- **语义色**：涨/对 = 绿 #00B578，跌/错 = 红 #FF4B4B（顺手教会用户"美股绿涨红跌"）
- 圆角卡片 + 按钮厚底边（多邻国式 3D 按压感），大字号、大点击区，手机优先（≤480px 主容器）
- 深色模式跟随系统

### 4.2 交互反馈

- 选中选项 → 紫色描边；点「检查」→ 底部弹出结果卡（绿 = 答对 + 夸奖 + 知识点；红 = 正确答案 + 解释）
- 答对「叮」、答错低音、通关琶音（WebAudio 合成，可在个人页关闭）
- 通关撒花动画 + XP 结算逐项弹出
- 错题当场重进队列（本关内再考一次，答对才算真会）

### 4.3 吉祥物与文案 Voice

- 吉祥物：**阿牛** 🐂——嘴碎但靠谱的牛市小牛，知识卡片和结算页由它出面
- 文案原则：夸人要具体（"连杠杆磨损都会算了？!"），损人要温柔（"没事，巴菲特也不是一天练成的"），禁止焦虑营销

## 5. 技术方案

- 纯前端 SPA：`index.html + css/style.css + js/app.js + js/data.js`，零依赖零构建
- 数据：题库 JSON（6 个单元文件 → 合并脚本校验后生成 `data.js`）
- 存档：localStorage（键 `bullcamp_state`），含 XP / 连胜 / 关卡进度 / 错题本 / 徽章
- 本地运行：`python3 -m http.server`，后续可直接套壳进 App WebView 或部署静态站
